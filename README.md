### Общая реализация:
В проекте инициализировано 2 базовых класса: `Product` и `Category` и 2 подкласса.
`Product`: Принимает список из имени, описания, цены и количества.
`Category`: Принимает список из имени категории, описания, списка продуктов.
`Smartphone` Принимает новые атрибуты такие как: производительность, модель, объем встроенной памяти, цвет.
`lawnGlass` Принимает новые атрибуты такие как: страна-производитель, срок прорастания, цвет.
